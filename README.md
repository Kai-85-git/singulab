# Singulab LLM ハッカソン

Singulab主催の **LLMベース社会シミュレーションハッカソン** に向けた、アイデア整理と設計ドキュメントをまとめるリポジトリ。

- **提出締切**: 2026-05-07(木) 17:00

## テーマ

LLMエージェントが住む小さな社会を構築し、**ルールでは書けない創発**が起きるかを観察する。

**3階層フレームワーク** に沿って世界を設計:

| 階層 | 役割 |
| --- | --- |
| **1階:物** | ペルソナ(年齢/性別/国籍/MBTI)・場所・所持物 |
| **2階:環境** | personal_context(家族/趣味/気分/悩み/専門ヒント) |
| **3階:物理** | 通信半径・認知上限・距離依存知覚 |
| エージェント | LLM搭載。1〜3階を知覚 → 思考 → 行動 → 世界にフィードバック |
