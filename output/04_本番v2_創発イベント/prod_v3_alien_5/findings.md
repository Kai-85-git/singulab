## 0. 総評 — 派閥形成と知覚分離の二重観察が成立

**前回(seg3_check)より明確に良くなった**。最大の収穫は **2 つの会話グループへの自然分裂**:

| グループ | 構成 | 発話傾向 |
| --- | --- | --- |
| **A(光・風グループ)** | Agent 0(57 男 INTJ)+ Agent 4(20 女 INFP) | 「左へ進んで光の違いを確認」「風が違う」← **間接的な異変感知** |

これは **段 3(イベント観察距離依存)+ 半径 5 m への縮小** が組み合わさって生んだ創発的な派閥分化。
**100 体での派閥観察の予行演習として極めて価値が高い結果**。

## 2. 観察された創発兆し

### 2-2. 役を演じない素の口調(Step 17)

> Agent 0:「**おっせえ**、少し歩くことで心が落ち着くのがわかってきた」

「おっせえ」という素の口調が出現。**役職直書き(prod_v2)では絶対出なかった種類の発話**。
personal_context へのピボットによる「生活の文脈ベース」アプローチが効いている。

### 2-3. 知覚の階層分化(Step 23-25)

| 知覚タイプ | 該当 Agent | 発話 |
| --- | --- | --- |
| **直接視認** | Agent 2 / 3 | 「UFO がまだ見えている」 |
| **間接感知** | Agent 0 / 4 | 「今朝の風、ちょっと違う感じがする」「光の違いを確認したい」 |

遠距離にいる人が UFO を直接見られず、代わりに「風」「光」の異変として表現。
これは **段 3 が狙った「Far 知覚不可 → 別の認識手段」の自然な発現**。

### 2-4. ペルソナ別の振る舞い(全体像)

| ペア | 主な話題 | UFO 発火後の反応 |
| --- | --- | --- |
| **Agent 0 ⇄ 4** | step 5 から「ドローンの空撮」「オフィスフロアの全貌」を議論 | **UFO に直接言及せず**、「風が違う」「窓の外の光」と間接知覚にとどまる |
| **Agent 2 ⇄ 3** | step 1〜10 は「風邪」「コーヒー」「机の片付け」など雑談 | step 21 から **明確に UFO を話題化**、「UFO が見える」「近づきたい」と方針転換 |

### 評価

- **echo_max 0.896**: 後半の Agent 2-3 ペアが「UFO 見えています」をループ気味に繰り返したため。ただし **完全コピペ(=1.000)には戻っていない**
- **self_similarity 0.400**: 派閥分裂のおかげで seg3 の 0.603 から **大幅改善**
- **右バイアス 24:16 ≒ 1.5:1**: seg3 の **68:0 から劇的に緩和**(おそらく半径縮小で「動かないと話せない」状況が増え、LLM が方向を真面目に選ぶ必要が出たため)

### 性別比率の効果

男性 4 人(INTJ ×2 / ISFP / ISTJ)+ 女性 1 人(20 歳 INFP)で、性別差は会話に直接的には強くは出なかったが、
**Agent 4(女性 INFP)が Agent 0 とペアを組んで「光・風」軸の会話を始めたのは個別性のひとつ**。
20 歳 INFP × 57 歳 INTJ という年齢/タイプ差ペアが「ドローンの空撮 → 光・風の異変」軸を駆動したのは、`expertise_hint: ドローン空撮` × `expertise_hint: 天文同好会` の専門領域マッチングが効いたと見られる。

## 5. 残課題(Qwen3 4B の限界)

- **エコー会話**: 直前のメッセージをほぼそのまま返す現象が頻発
  - 例: step 24 Agent 4 → 0「今朝の風、あなたも感じましたか?…」(step 23 の Agent 0 → 4 と同文)
  - 例: step 8/10 Agent 4 → 0「オフィスフロアの奥まったり、廊下を少し歩くことが出来ますか?」(コピーバック)
- **対話ループの硬直**: Agent 2-3 ペアが step 21〜26 で「UFO がまだ見える / 行きたい / ご意見を」を **6 step 連続で同じ言い回し**。具体的な移動・合意形成には至らず
- **英単語の混入**: `sometimes` / `that` / ` similar` / ` previously` / `things` / `became` が複数発話に出現(abliterated 系の品質劣化)
- **単調移動**: Agent 0/4 が step 16 以降「西へ → 東端 x=25 で clamp」を 5 step 以上繰り返し、UFO 方向 (-15, 12) には向かわず
- **後半メッセージ枯渇**(step 27-30):seg3_check と同傾向。100 体スケール時には `simulation.duration` を伸ばすか、ペアの再編成を促す仕組みが要検討

## 6. 結論

- ✅ **派閥形成と知覚分離の二重観察が成立** — 半径 5 m + 段 3(距離依存)で、5 体でも 2 グループに自然分裂し、100 体本番の予行演習価値が高い
- ✅ **personal_context へのピボット(2026-05-01 実装)は機能している** — `today_mood` `recent_concern` `expertise_hint` が会話に流入。Step 17「おっせえ」のような **役を演じない素の口調** も出現
- ✅ **AlienEvent の距離依存知覚が狙い通り作用** — 直接視認(B)/ 間接感知(A)の階層分化が確認できた
- ✅ **数値指標も改善傾向** — self_similarity 0.603 → 0.400、右バイアス 68:0 → 24:16
- ⚠ **echo_max 0.896 は依然高い** — 100 体ラン前にエコー抑制(プロンプトに「相手の文をそのまま返さない」を追加 / repetition_penalty)を検討
- ⚠ **英単語混入の頻度は粉川氏共有時のリスク** — 100 体ランを 4B で回す前に、`huihui_ai/qwen3-abliterated:8b` か別モデルとの簡易比較を勧める
