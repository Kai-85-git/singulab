## 4. 観察された個性化の例

step 1 の発話を MBTI 別に並べると、性格次元が反映され始めている:

```
Agent 0 (ENFP, インド, 25歳): 「コーヒーを飲もう」          ← 外向 / 行動的
Agent 1 (ISFP, インド, 55歳): 「静かに生きている」          ← 内向 / 受容的(ISFP らしい)
Agent 2 (INTJ, ブラジル, 48歳): 「静かな午前中」            ← 内向 / 観察
Agent 3 (ISTJ, ドイツ, 47歳): 「コーヒーを飲みましょう」    ← 内向 / 規律的(誘い方が丁寧)
Agent 4 (ENTP, ドイツ, 33歳): (発話省略)                   ← 該当 step では沈黙
```

ENFP / ENTP の外向系と ISFP / INTJ / ISTJ の内向系で、**発話量と語尾のフォーマル度に差**が出始めた。
N = 1 試行のため統計主張はできないが、対策前の「全員同じ常套句」状態からは明確に脱却している。

## 5. 残課題

### 5-1. `echo_max=1.000` が残る理由(M-08 と同じ)

短文化(max_tokens=100)の副作用で、**短い表現のレパートリーが小さい**ため偶然一致が発生する。
たとえば「コーヒーを飲もう」と「コーヒーを飲みましょう」は別の文だが、4-gram で見ると共通部分が多く類似度が高くなる。
これは「コピペ的伝染」とは性質が異なる。

### 5-2. `reflection_mean=0.033` が低すぎる可能性

健全レンジは 0.1〜0.3。0.033 は **「受信メッセージをほぼ無視している」** 状態に近い。
つまり「会話していない」が「コピペしていない」だけになった可能性。
**ステージ C(創発イベント)で強い揺らぎ(宇宙人 / 無重力)を入れて、状況依存の自然な反応を引き出す**ことで改善する見込み。
