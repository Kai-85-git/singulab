## 1. 動機

[M-05 で `think: false` 解決](2026-04-29_qwen3_no_think解決.md) した直後の本番ラン(prod_local_startup)で、agent の発話が **全て中国語** になる事象が発生。例:

```json
{"step": 6, "from": 3, "to": 0,
 "message": "大家好，我同意大家的建议。现在办公室人不多，确实可以考虑调整工作安排..."}
```

ペルソナは日本語(「あなたは田中(男性)、地方にあるスタートアップで働く3年目のエンジニアです。」)で与えていたが、システムプロンプト全体が英語ベースだったため、Qwen3 abliterated が母語(中国語)バイアスに流れた。

これは [M-04 対話確認](2026-04-28_qwen3-4b-abliterated_対話確認.md) で日本語応答が確認できていた事象と矛盾する。違いは:

- M-04: ターミナル `ollama run` で **日本語直接入力**(プロンプト全体が日本語)
- 本番ラン: `agent.py` のシステムプロンプトが **英語ベース**(persona セクションのみ日本語)

## 2. 検証

### 2.1 比較対象

ペルソナ直後に **`=== LANGUAGE REQUIREMENT ===` セクション** を入れる前後で同条件 3 試行。

```
=== LANGUAGE REQUIREMENT (CRITICAL) ===
All JSON string values (message, reasoning, memory) MUST be written in Japanese (日本語).
Do NOT use Chinese, English, or romaji. 日本語以外は不可。
```

### 2.2 結果(`/api/generate`、`temperature=0.5`、`num_predict=512`、`think: false`)

| ID | 中国語のみ | elapsed | eval_count |

| BEFORE t1 | ✅ Yes | 6.57s | 87 |
| BEFORE t2 | ✅ Yes | 7.25s | 95 |

| **AFTER t2** | **❌ No** | **7.16s** | **97** |
| **AFTER t3** | **❌ No** | **6.80s** | **98** |

**判定:** BEFORE 3/3 中国語のみ、AFTER 0/3 中国語のみ。明確に効果あり。
速度オーバーヘッドは無視できるレベル(+0.5s 程度)。

### 2.3 出力例の比較

**BEFORE(中国語のみ):**

> "message": "大家好，最近公司资金紧张，项目推进有些困难。我想和大家商量一下，是否可以调整一下工作节奏..."

**AFTER(日本語):**

> "message": "景気は悪いし、資金繰りも厳しいです。でも、私たちが一つ一つ頑張ればきっと乗り越えられると思います。どうか、今後ともよろしくお願いします。"

> 注: AFTER も「агент(キリル文字)」「things(英単語)」がまれに混じるが、ベースは完全な日本語。提出物として十分な品質。

## 3. 実装

[src/agent/agent.py](../../src/agent/agent.py) の `_build_persona_section` を更新:

```python
def _build_persona_section(self) -> str:
    """ペルソナ文(日本語)を YOUR CURRENT STATE 直前に挿入するセクション。

    Qwen3 系は abliterated でも母語(中国語)に流れることがあるため、
    ペルソナがある = 日本語シナリオなので、明示的に日本語出力を強制する。
    """
    if not self.persona_fragment:
        return ""
    return (
        f"\n=== PERSONA ===\n{self.persona_fragment}\n"
        f"\n=== LANGUAGE REQUIREMENT (CRITICAL) ===\n"
        f"All JSON string values (message, reasoning, memory) MUST be written in Japanese (日本語).\n"
        f"Do NOT use Chinese, English, or romaji. 日本語以外は不可。\n"
    )
```

`persona_fragment` が空(従来の Phase 1/2 シナリオ)の場合は何も挿入しないので、**既存テストへの影響なし**。
