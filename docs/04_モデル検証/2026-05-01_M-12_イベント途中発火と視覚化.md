## 4. 観察された創発

### 4.1 UFO 着地点を agent が発話で参照(alien_5 step 15)

```text
[step 15] a0 → a2:
  「今、UFOが(-15, 12)の近くを通りました。main_officeでは5人いて、
   ドローンの飛行も確認しました。今後はどこを確認すべきですか？」

[step 15] a2 → a0:
  「UFO の動きを確認するために、小会議室 A のモニタをもう少し詳しく見てみたいと思います。」
```

→ agent が **prompt の `events.alien.position` を読んで具体的な座標を発話に取り込んだ**。
これは「視覚化(prompt_text に座標を含める)」が LLM の発話に効いていることの直接証拠。

### 4.2 UFO の動きへの追従反応(alien_5 step 17)

物理層で `events.jsonl` を見ると、

- step 18: agent 3 が main_office を退出
- step 19: agent 0 が main_office を退出
- step 23-25: agent 4 が `(26, -6)` への移動を試み、フィールド境界 `(25, -6)` でクランプ

→ agent 4 は UFO 方向(主に左上)とは逆方向(右下)に向かったが、別の agent はオフィスを出て外へ。
LLM の自由意志で動く agent + Python が物理境界を強制する組み合わせが機能している。

### 4.3 step 15 の質的ピボット比較

| 段階 | alien_5 | zero_gravity_5 |
| --- | --- | --- |
| step 13(発火前) | 「ドローンの飛行状況を確認」「モニタの場所」 | 「ホワイトボードの端が曲がっている thing」← 既に異常? |
| **step 15(発火)** | 「UFOが(-15, 12)の近くを通りました」「UFOの動きを確認」 | (詳細は後段) |

zero_gravity_5 で step 13(発火前)に「ホワイトボードの端が曲がっている」発話があったのは興味深い。seed=42 と prompt の偶然か、何らかの "前兆" として agent が空間の異変を感じたか、要検証。

## 5. 数値指標の変化

step 1 発火・15 step 版(M-10)と比較:

| 指標 | M-10 alien_5 (15 step、step 1 発火) | M-12 alien_5 (30 step、step 15 発火) |
| --- | ---: | ---: |
| echo_mean | 0.012 | 0.149 |
| echo_max | 0.889 | 1.000 |
| reflection_mean | 0.138 | 0.463 |
| self_similarity | 0.027 | 0.337 |

**数値だけ見ると悪化**。原因仮説:

- duration を 15 → 30 に倍増 → 前半 14 step の業務会話で似た発話が累積する時間が増えた
- `conversation_profiles` で各 agent に「役割」を与えたため、定型的な役割演技に流れる場面が増えた([M-11 自然会話と役の問題](2026-05-01_M-11_自然会話と役の問題.md) で議論された通り)

ただし **質的観察(発火後のピボット、UFO 座標参照、物理移動)は明確に出ている**ので、定量指標の悪化は数値そのものの問題というより「日常パートが長く / プロフィールで似た色になった」副作用。

→ **次の改善**: `conversation_profiles` を `personal_context`(M-11 で設計した生活の文脈型)に置き換えて、役を演じない自然会話を取り戻す。
