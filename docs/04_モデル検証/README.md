# 04_モデル検証

採用候補 LLM の **実機での挙動確認ログ** を格納するフォルダ。

> 環境構築タスク自体の検証ログ([docs/03_ToDo/verifications/](../03_ToDo/verifications/))とは目的が異なる。
>
> - `03_ToDo/verifications/` = **タスクの完了証跡**(C-01〜C-06 のチェックリスト記録)
> - `04_モデル検証/` = **モデルの振る舞い記録**(同じモデルを複数条件で試した結果、品質判断の材料)

## このフォルダの狙い

1. C-06 で発覚した「日本語ペルソナ品質の問題」を **複数条件で再検証** し、原因を切り分ける
2. 「採用 vs 不採用」の判断材料を 1 か所に集約する
3. 設計書 [02_LLMモデル/2026-04-24_選定と推奨/](../01_設計書/02_LLMモデル/2026-04-24_選定と推奨/) を改訂するときの根拠を残す

## ファイル命名規則

```
YYYY-MM-DD_<モデル短縮名>_<検証種別>.md
```

例:
- `2026-04-28_qwen3-4b-abliterated_対話確認.md`
- `2026-04-28_qwen3-4b-abliterated_no_thinkテスト.md`(予定)
- `2026-04-28_qwen3-4b-abliterated_vs_qwen3-4b公式比較.md`(予定)
