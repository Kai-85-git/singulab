2026-04-29 議事録 §3.2 で採用した **創発イベント(プラン B)= 宇宙人 / 無重力** で、状況依存の自然な反応を引き出して会話を正常化できるかを検証する。

特に **`zero_gravity_5` ですべての指標が健全レンジ内**。`echo_max=0.333` はギリギリだが、これは「重力はもういい」のような短文の偶然一致レベルで、**コピペ的伝染ではない**。

### 3.2 創発の質感(発話例)

**宇宙人シナリオ step 1:**

```
Agent 0 (?, インド, 25歳):    「少しの変化が楽しみです」(好奇心 / 期待)
Agent 1 (?, インド, 55歳):    「未知の存在に注目する」(冷静 / 観察)
Agent 2 (?, ブラジル, 48歳):   「未来は今ここにあります」(哲学的 / 現在志向)
Agent 3 (?, ドイツ, 47歳):     「静かな昼」(落ち着き / 距離をとる)
Agent 4 (?, ドイツ, 33歳):     (この step は沈黙)
```

**無重力シナリオ step 1:**

```
Agent 0:  「重力のない世界は、自由だ」(肯定的 / 解放感)
Agent 1:  「重力はもういい」(受容 / 諦観)
Agent 2:  「希望」(楽観)
Agent 3:  「静かに動け」(慎重 / 助言)
Agent 4:  (省略)
```

→ **同じイベントに対して、agent ごとに違う角度から反応している**。これは Phase 4-A の旧本番ラン(全員「景気の悪さは~コスト削減を~」と定型句)と決定的に異なる。

### 3.3 発話量分布

両シナリオ共通の傾向:**5 人中 1 人が極端に少ない発話**(Agent 0 で 3〜4 回、他は 12〜15 回)。
これは Phase 4-A でも観察された「規模が押し付ける役割分化」と同じ性質で、5 人でもすでに発話量の偏りが出る。

```
prod_v2_alien_5 発話量:        Agent 1=15, Agent 2=15, Agent 3=15, Agent 4=12, Agent 0=4
prod_v2_zero_gravity_5 発話量: Agent 1=15, Agent 2=15, Agent 3=15, Agent 4=14, Agent 0=3
```

## 4. 解釈

- **創発イベントが「会話のアンカー」を提供した**。状況が固定的だと agent は generic なことしか言えないが、宇宙人 / 無重力という共有イベントがあると **そのイベントへの自分なりの反応** を述べるようになる
- 結果として `reflection_mean` が 0.138 まで戻り、agent 同士が話を踏まえつつも、自分の言葉で返している(健全な会話の構造)
- `echo_max` の zero_gravity = 0.333 はほぼ偶然一致レベルで、**完全コピペは消滅**

## 5. ステージ A〜C の総合評価

| 改善 | 寄与 | 確認指標 |
| --- | --- | --- |
| プロンプト粒度(A-1-1) | コピペ誘発を断つ | echo_mean -88% |
| 短文化 + 多様性(A-1-3/4) | 定型句で字数を稼ぐループを断つ | self_similarity -61% |
| MBTI / 国籍多様性(B) | 個性の入り口 | reflection 過小化を経て C で復元 |
| 創発イベント(C) | 状況依存の反応を引き出す | echo_max 1.000 → 0.333、reflection 健全レンジ復帰 |

**A → B → C の順番で重ねたことで全指標が健全化**。一発で全変更を入れていたら何が効いたか切り分けできなかった。
