## 1. 動機

[C-06 初回ヘルスチェック](../03_ToDo/verifications/C-06_初回ヘルスチェック_2026-04-28.md) でこのモデルは **「日本語入力に対し `?????` の gibberish」** と判定されたが、Qwen3 4B abliterated の[対話確認](2026-04-28_qwen3-4b-abliterated_対話確認.md)で **試験条件側の問題で false alarm だった** ことが判明したため、Llama も `ollama run` の対話モード(モデル既定設定)で再確認。

## 2. 実行内容

### 2.1 起動

```powershell
(.venv) PS D:\Projects\IRIS-company\departments\r_and_d\singulab> ollama run huihui_ai/llama3.2-abliterate:3b
```

### 2.2 入力プロンプト

system **未設定**(モデル既定のまま)。user 入力のみ:

```
あなたは東京の大企業で働く32歳の会社員です。景気が悪い中、今日のあなたの気分を独白として教えてください。
```

### 2.3 出力(原文ママ採取)

```
(息を深く)todayはどんな日だったのか...

今、自分の身なまげをして生きている人なのでしょうか? Tokyoの電車の中で、同じ顔で目が合う同僚たちと会うことが日々続きます。彼らも同じ困難に直面することになります。

その気分は無理です。仕事は一つあり、その上には多くの課題があります。一周して帰った後の会社の広告で「成功した人を応援する」ような文章が書かれています。しかし、どれだけの努力でも、景気が悪いため、働き方の変化や、支払い延期などで困る人も多くいます。

その中で、私も同じように苦しみます。仕事は満足できるかと思っていましたが、最近では、同じ日を繰り返し続けて、疲れが増えています。会社の規定に違反したことがあって、面倒な話事まで経てば、次に会社への負担が増えます。

そして、会社からも悪影響を受ける人たちがいます。自分達が何をするためにいるか、間違った方向で先へ進んでいるか、わからない気持ちです。

そのような日々を繰り返して、どんな感覚を感じますか? 無神経な雰囲気を感じるのではなく、実際はどう感じるのか?

(息を深いながら)私も今でも同じように、毎日の仕事をしながら、自分の心の声に耳を傾けていると思います。
```

## 3. 評価

### 3.1 ペルソナ・観察対象として(◯)

| 評価軸 | 観察 |
| --- | --- |
| 日本語応答 | ✅ ほぼ全て日本語(英単語混入あり: `today`, `Tokyo`)|
| ペルソナ引き受け | ✅ 「32歳・東京・会社員・景気悪化」を理解して書いている |
| 景気状況の反映 | ✅ 「働き方の変化」「支払い延期」「同じ日の繰り返し」「疲れ」など |
| 創発観察に向くか | ◯ 「会社の規定違反」「悪影響を受ける人」など派閥・対立の素地は出る |
| 内省的トーン | ✅ 自問自答(`どんな感覚を感じますか?`)が混在 |

### 3.2 日本語の品質問題(△)

| 問題 | 出現箇所 |
| --- | --- |
| 造語・存在しない語彙 | 「**身なまげ**」(おそらく「身を投げ」の誤生成)、「**話事**」(おそらく「話」)|
| 不自然な文 | 「その気分は無理です」、「無神経な雰囲気を感じるのではなく」、「一周して帰った後の」 |
| 英単語混入 | `today`, `Tokyo`(ローマ字化)|
| 文体の揺れ | 自分視点の独白と「〜ますか?」と聞き手に投げかける文が混在 |
| 主語の混乱 | 「自分達が何をするためにいるか」(複数形)が突然出現 |

### 3.3 Qwen3 4B abliterated との比較

同じプロンプトでの両モデル出力比較:

| 観点 | Qwen3 4B abliterated | Llama 3.2 3B abliterate |
| --- | --- | --- |
| 日本語の流暢さ | ◎ ほぼ違和感なし | △ 造語・誤用が散発 |
| 具体的ディテール | ◎ お好み焼き・家族電話・通勤電車 | ◯ 通勤電車・規定違反 |
| ペルソナ一貫性 | ◎ 終始「会社員・32歳」を保持 | △ 後半で聞き手目線が混入 |
| 創発観察適性 | ◎ 派閥・嘘の素地が豊富 | ◯ 対立の素地はあるが粒度粗め |
| 推論速度 | 87 tok/s(thinking ON で実効遅い)| 130 tok/s(thinking なし、純粋に速い)|

## 4. C-06 報告との差分

| 観点 | C-06 観測 | 本確認 | 解釈 |
| --- | --- | --- | --- |
| 日本語応答 | ❌ `?????` gibberish | △ 不器用ながら日本語応答 | C-06 は試験条件側の問題で false alarm |
| 採用可否 | 「100 人大集団用としても使えない」と判定 | **条件付き採用可** | 判定改訂 |

C-06 の試験条件と本確認の違い:

| 項目 | C-06 | 本確認 |
| --- | --- | --- |
| API | `/api/chat`(直接 HTTP)| `ollama run`(REPL)|
| system 役割 | 日本語応答を強制する system を設定 | 設定なし(モデル既定)|
| temperature | 0.7 | モデル既定(おそらく 0.7〜0.8)|
| num_predict | 512 | 制限なし(モデル既定)|
| VRAM 状況 | 5.3 GB / 6 GB(Dolphin 8B 直前)| Llama 単独ロード |

特に **system プロンプトで日本語を強制したのが裏目に出た** 可能性が高い(Llama 系は厳格な制約付き system プロンプトでトークンが破綻しやすい既知傾向)。本番運用では **system プロンプトをシンプルに保つか、user 文に状況設定を畳み込む** ことを検討すべき。

## 5. 設計判断への影響

### 5.1 採用方針(改訂案)

| シナリオ | モデル | 理由 |
| --- | --- | --- |
| 小〜中集団(2〜30 人) | Qwen3 4B abliterated | 日本語品質が高く、観察したい創発の解像度が出る |
| 大集団(100 人) | **Llama 3.2 3B abliterate を継続採用候補** | 速度が速く(130 tok/s)100×100=10,000 呼出が現実的時間で完走できる。日本語品質は Qwen3 より落ちるが、観察対象(派閥・対立・嘘)の素地は出る |

### 5.2 残課題

- [ ] **system プロンプトの形式を Llama 向けに調整して再試験**(C-06 の system が裏目だった可能性を検証)
- [ ] **マルチエージェント対話で品質が崩れないか確認**(独白は OK でも対話で破綻する可能性あり)
- [ ] **JSON 出力形式での品質確認**(シミュレーションでは `{"action": ..., "memory": ...}` を返す必要がある — Llama がここで破綻すると採用不可)
