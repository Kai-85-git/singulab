## 進め方ルール

- **着手するときは [02_実装ロードマップ.md](02_実装ロードマップ.md) の該当チェックボックスを `[ ]` → `[~]`(進行中)に変える**
- **完了したら `[x]` に変える**
- **ブロッカーが出たら同じ行に「⚠️ ブロック: ◯◯待ち」を追記**
- 大きな仕様変更が必要になったら [01_設計書/](../01_設計書/) 側を直し、本ファイルの該当行に「→ 設計更新済み」と書く
