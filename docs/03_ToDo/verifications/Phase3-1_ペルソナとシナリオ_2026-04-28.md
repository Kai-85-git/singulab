## 3. 統合スモークテスト

### 3.1 シナリオ([config/scenario_local_startup.yaml](../../../config/scenario_local_startup.yaml))

4 象限の中で **最も尖った象限**(地方 × スタートアップ × bad)を選択:

- 5 体 × 5 ステップ
- `random_in_place / home_place: main_office`
- `cognitive_limit: 10`(全員把握可能)
- `economy: bad`

### 3.2 結果

#### 生成されたペルソナ(run_metadata.json から)

```
- 木村 (male, 社歴1年, エンジニア) @ 地方×スタートアップ
- 井上 (male, 社歴4年, リーダー)   @ 地方×スタートアップ
- 山田 (male, 社歴1年, リーダー)   @ 地方×スタートアップ
- 井上 (male, 社歴3年, エンジニア) @ 地方×スタートアップ
- 森   (male, 社歴3年, 平社員)     @ 地方×スタートアップ
```

→ name_pool / role_distribution / tenure_range が乱数で組み合わせられた多様なペルソナが生成された。同姓(井上)も自然に発生(本物の組織と整合)。

#### LLM 応答にペルソナ + 景気が反映された証拠

```json
{"step": 1, "from": 0, "to": 2,
 "message": "大家好，今天办公室的气氛似乎有些低落。作为新人，我想分享一下自己的感受和观察。尽管目前景气不佳，但我相信通过团队合作可以克服这些挑战。",
 "reasoning": "希望通过分享自己的感受和对未来前景的看法来缓解当前的紧张氛围，并鼓励同事们相互支持。"}
```

| キーワード | 対応する設定 |
| --- | --- |
| 「办公室的气氛似乎有些低落」(オフィスの空気が落ち込み気味) | economy=bad |
| 「**作为新人**」(新人として) | 木村は社歴 1 年 |
| 「**尽管目前景气不佳**」(目下の景気が悪いにもかかわらず) | economy=bad |
| 「通过团队合作可以克服」(チームワークで乗り越える) | スタートアップ的な協働文脈 |

→ **設計書 [03_1階-物/06_4象限との関係 §5](../../01_設計書/03_1階-物/06_4象限との関係.md) の「状態記述として与えるとペルソナが自然に景気を反映する」想定通り** に動作している。

## 6. 注記

### 6.1 num_agents が本番より控えめ

設計書の 4 象限定義では、urban_enterprise = 100 体・urban_startup = 5 体程度を想定しているが、Phase 3-1 のスモーク確認では各シナリオ 5〜10 体に絞った(動作確認に集中するため)。本番ラン(Phase 3-3)で 100 体に上げる。

### 6.2 LLM が中国語で応答

qwen2.5:3b は中国語強化モデルで、persona に「日本人らしい名前」を与えても応答は中国語で返ることが多い。日本語応答が必要なら **Qwen3 4B abliterated**(MAIN 候補)に切り替える。Phase 3-3 の試走ではモデル切り替えの影響を測る。

### 6.3 Phase 1 互換

`agents.persona` を持たないシナリオ(例: [scenario_bar_fire.yaml](../../../config/scenario_bar_fire.yaml))は **そのまま動作**。Persona 注入はオプショナルなため Phase 1 互換性が保たれている。
