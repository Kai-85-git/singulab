## 5. 注記

### 5.1 「system prompt」の扱い

設計書では「system prompt 末尾に挿入」と明記されているが、現在の Agent prompt 構造は **system / user の分離なく単一文字列**(参考実装由来)。Phase 3 でプロンプトを system + user に分割するときに、景気文は system 末尾へ移動する想定。今回は `=== YOUR CURRENT STATE ===` 直後に固定で挿入。

### 5.2 LLM の景気反応の強さ

qwen2.5:3b は景気 bad の状態描写を強く取り入れた(「economic conditions」「budgets and employment」「面临挑战」)。これは **観察したい創発(派閥・反乱・嘘)の前提条件として効きすぎる可能性** もある。Phase 3 の比較実験で景気を good / neutral / bad で振って、どの程度 LLM が「景気のせいで〜」と過剰に説明するかを評価する。

### 5.3 動的注入の設計余地

現状は **エージェント生成時に 1 回 environment_fragment を渡して固定** しているが、設計書 [06_実装方針 §4](../../01_設計書/04_2階-環境/06_実装方針.md) と整合する。将来的に景気を動的に変えたい場合は、`Agent.environment_fragment` を毎ステップ更新する API を追加する形で拡張可能。
