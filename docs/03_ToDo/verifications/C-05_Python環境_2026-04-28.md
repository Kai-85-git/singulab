## 4. 観察と注記

- **Python は Microsoft Store 版** を使用。コマンドラインから `python` コマンドが起動するように既に PATH 設定済み(`%LOCALAPPDATA%\Microsoft\WindowsApps`)。venv 作成時に Store 版特有の制限(stub launcher)による問題は **発生しなかった**。
- pip を **23.0.1 → 26.1 へ自動アップグレード**(install 前)。古い pip だと依存解決で警告が出ることがあるため。
- `requests` は設計書本文にあったが、実装方針では `httpx` を使う方針(同期/非同期両対応)であり、`requests` は不要と判断し install しなかった。
- Phase 1 以降で `pytest` を追加する見込み(本フェーズの実行モジュールには不要なため未インストール)。
