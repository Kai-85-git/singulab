## 3. 観察と注記

- インストールは **過去に実施済み**。winget での新規インストールは不要だった。
- バージョン 0.21.2 は要件 0.6 を**大幅に**上回り、Gemma 3 系含む全新モデルに対応。
- 既存の `qwen2.5:3b` は **参考実装** [`docs/10_共有資料/2d-multi-places-simulation-on-fire-public/config.yaml`](../../10_共有資料/2d-multi-places-simulation-on-fire-public/config.yaml) のデフォルトモデル。今回採用する 3 モデル(qwen3-4b / llama3.2-3b / dolphin3-8b)は **C-04 で改めて pull** する。
- 設計書では `llama3.2:1b` で起動確認するよう書かれているが、**ハッカソンで使わない 1B モデルを今 pull する必要はない** と判断し、既存の qwen2.5:3b で代替。本質(API が応答する)は同じ。
- HTTP API の初回応答 7.6 秒は **モデルの初回ロード時間** が支配的。継続呼び出しでは eval_duration 15 ms / 2 token 程度で本来速度が出る。
