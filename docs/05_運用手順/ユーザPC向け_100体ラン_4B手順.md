# ユーザ PC 向け:100 体ラン実行手順(Qwen3 4B、2026-05-01)

> ユーザ PC(RTX 3060 Laptop 6GB / 16GB RAM / Windows 11)で **Qwen3 4B abliterated** を使い
> **100 体 × 宇宙人 / 無重力** を完走させるための手順書。
>
> 粉川氏マシン用の 34B 版手順([粉川氏向け_100体ラン手順.md](粉川氏向け_100体ラン手順.md))の **ノート PC 版**。
> 提出物本番ランは粉川氏マシンの 34B、本書は **参考データ取得用 / 4B 品質ベンチマーク用**。

---

## 1. 用途と位置づけ

このランは **本番提出物には使わない**。目的は以下の 3 つ:

1. ユーザ PC で 100 体スケールが動くことの確認
2. `personal_context` などペルソナ拡張の効果を 100 体スケールで観察(34B 待ちの間)
3. 34B vs 4B の品質差ベンチマーク

> **F-2 ルール**: 1 時間以上かかる逐次ランなのでユーザ承認が必須。
> 本書を実行する前に「100 体 4B ラン回しても OK か?」を 1 行確認すること。

---

## 2. 前提環境

| 項目 | 推奨/必須 | 確認方法 |
| --- | --- | --- |
| GPU | RTX 3060 Laptop 6GB(VRAM 6GB)以上 | `nvidia-smi` |
| AC 電源 | **必須** バッテリ駆動だと GPU が絞られて 2 倍以上遅くなる | 物理的に AC 接続 |
| 冷却 | 冷却台 + ファン最大モード推奨 | サーマルスロットリング回避 |
| OS スリープ | **無効化必須**(数時間連続稼働) | `powercfg /change standby-timeout-ac 0` |
| Ollama | 0.21+(`think: false` 対応版)| `ollama --version` |
| モデル | `huihui_ai/qwen3-abliterated:4b`(2.7GB)pull 済 | `ollama list \| grep qwen3-abliterated` |
| Python | 3.10+ | `python --version` |
| ffmpeg | 動画生成用(`tools/generate_video.py` 使用時)| `ffmpeg -version` |

## 3. 実行前チェックリスト

下のチェックを **すべて埋めてから実行**。1 つでも空欄があれば実行しない。

### 3.1 ハードウェア

- [ ] AC アダプタを接続している(バッテリ駆動ではない)
- [ ] 冷却台 / 外付けファンを起動している、またはサーマル余裕がある場所に置いてある
- [ ] PC のスリープ・休止が無効化されている
  ```powershell
  powercfg /change standby-timeout-ac 0
  powercfg /change hibernate-timeout-ac 0
  powercfg /change monitor-timeout-ac 0
  ```
- [ ] Windows Update が走らないタイミングを確保している(深夜帯は要注意)

### 3.2 Ollama 環境

- [ ] Ollama が起動している(`curl http://localhost:11434/api/tags` が 200)
- [ ] モデルが pull 済み:`ollama list | grep qwen3-abliterated`(`huihui_ai/qwen3-abliterated:4b` が出ること)
- [ ] `OLLAMA_NUM_PARALLEL` を環境変数で設定済(下表参照)

| 並列度 | VRAM 余裕 | 想定時間 | 備考 |
| --- | --- | --- | --- |
| 1 | 余裕大 | 約 28 時間 | 安全だが遅すぎる |
| 4 | やや余裕 | 約 6〜7 時間 | **推奨**(OOM リスク低) |
| 8 | ギリギリ | 約 3.5 時間 | OOM リスクあり、ラン中断可能性 |

```powershell
# 例: 4 並列で起動
$env:OLLAMA_NUM_PARALLEL = 4
ollama serve
```

> 既に Ollama がサービスで動いていると環境変数が効かないので、一旦 `Stop-Service ollama` してから上記実行する必要あり。

### 3.3 リポジトリ・コード状態

- [ ] `git status` がクリーン or コミット済み(ラン中に予期せぬ変更が入らない)
- [ ] `tools/check_design_freshness.py` を通している(議事録 → 要件定義 → 実装の整合)
  ```bash
  python tools/check_design_freshness.py
  ```
- [ ] 出力先ディレクトリが存在しない or 上書き OK(`output/test_4b_*` 推奨、`output/prod_v2_*` を上書きしない)
- [ ] `pytest` の主要テストが通る(任意、5 分程度)

### 3.4 ペルソナ・シナリオ

- [ ] 国籍配分が想定通り(日本人 90% / 外国人 10%)
  ```bash
  python -c "from src.config_loader import load_config; cfg=load_config('config/scenario_alien_100_4b.yaml'); print(cfg['agents']['persona']['nationality'])"
  ```
- [ ] `conversation_profiles` が空(`[]`)であることを確認(num_agents=100 と数が合うため)
- [ ] 会議室 capacity=6、main_office capacity=200 を確認

### 3.5 監視・ログ

- [ ] `output/test_4b_*` のディスク空き容量が 5GB 以上(フレーム PNG 100 枚 + ログ)
- [ ] ターミナルが閉じても続くように `nohup` または別ターミナル / バックグラウンドで実行する計画
- [ ] 経過確認の方法を決めている(別ウィンドウで `tail -f output/test_4b_*/simulation.log`)

## 4. 実行コマンド

```bash
# 宇宙人イベント(100 体 × 100 step)
python -m src.main \
  --config config/scenario_alien_100_4b.yaml \
  --output-dir output/test_4b_alien_100

# 無重力イベント(100 体 × 100 step)
python -m src.main \
  --config config/scenario_zero_gravity_100_4b.yaml \
  --output-dir output/test_4b_zero_gravity_100
```

> 連続実行する場合は **片方が完走してから次を起動**(同時並列は VRAM 不足で OOM 確実)。

## 5. 完走時間の目安

| シナリオ | エージェント数 | step 数 | LLM 呼出/step | 1 呼出 | 並列度 | 完走時間 |
| --- | --- | --- | --- | --- | --- | --- |
| `scenario_alien_100_4b` | 100 | 100 | 200(message + action) | 約 5 秒 | 4 | **約 7 時間** |
| `scenario_alien_100_4b` | 100 | 100 | 同上 | 同上 | 8 | **約 3.5 時間**(VRAM ギリギリ) |
| `scenario_zero_gravity_100_4b` | 100 | 100 | 同上 | 同上 | 4 | **約 7 時間** |

実測ベース: 5 体ラン([output/prod_v2_alien_5/simulation.log](../../output/prod_v2_alien_5/simulation.log))で
1 LLM 呼出 ~5 秒 / 4B モデルでの並列処理性能から推定。

### 6.4 観察ポイント

- **会議室 capacity の効果**: `events.jsonl` で `place_entry_denied` の件数 → 100 体スケールで 1 階(物)層が初めて意味を持つか
- **エコー指標**: 5 体ラン と比較して echo_mean / reflection_mean が悪化していないか(集団規模の増加で同質化が進む可能性)
- **沈黙率**: 何 % の agent が一度も発話しないか(規模が押し付ける役割分化)
- **国籍効果**: 日本人 87 名 vs 外国人 13 名で発話傾向に差があるか(国籍観察)
- **34B との品質差**: 同じシナリオの 34B ランと文章品質を比較(主観で OK)

## 7. トラブルシュート

| 症状 | 原因 | 対処 |
| --- | --- | --- |
| `CUDA out of memory` | OLLAMA_NUM_PARALLEL が高すぎる | 並列度を 1 段下げる(8 → 4 → 2) |
| 速度が想定の半分以下 | バッテリ駆動 / サーマルスロットリング | AC 接続確認、冷却強化、放熱性能確認 |
| `model 'huihui_ai/qwen3-abliterated:4b' not found` | モデル未 pull | `ollama pull huihui_ai/qwen3-abliterated:4b` |
| 中国語混入 | LANGUAGE REQUIREMENT 抜け | [docs/04_モデル検証/2026-04-30_qwen3_中国語混入対策.md](../04_モデル検証/2026-04-30_qwen3_中国語混入対策.md) 参照 |
| `agents.conversation_profiles must have exactly num_agents entries` | 5 体用 5 件が継承されている | yaml で `conversation_profiles: []` 明示済か確認 |
| ラン途中で OS スリープ | スリープ無効化漏れ | §3.1 のチェック再確認 |
