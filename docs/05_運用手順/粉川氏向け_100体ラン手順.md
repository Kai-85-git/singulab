## 3. シナリオ yaml の調整

### 3.1 100 体スケール対応(2026-05-01 改訂済、確認のみ)

[config/scenario_alien_100.yaml](../../config/scenario_alien_100.yaml) と [config/scenario_zero_gravity_100.yaml](../../config/scenario_zero_gravity_100.yaml) は **100 人が現実的な密度でオフィスに収まるよう** 以下の数値で確定済み(粉川氏側で再調整は不要、参考のため記載):

| 項目 | 値 | 意図 |
| --- | --- | --- |
| `simulation.half_space_size` | **50**(フィールド 100×100) | 5 体版の 25 から拡大 |
| `places.main_office.half_size` | **20**(40×40 = 1600 sq) | 100 人 × 16 sq/人 = 4×4 m/人で現実的 |
| `places.main_office.capacity` | **120** | 100 体 + 余裕 |
| `world_laws.communication_radius` | **15.0** | 5 体版の 10.0 から拡大(集団反応を観察可能に) |
| `events.alien.center_x, center_y`(alien のみ)| **(-35, 30)** | UFO は main_office (-20..20) の外側に着地 → 段 3(イベント観察距離依存)で「窓際の人だけ Mid 視認、奥側は会話伝播でのみ知る」を観察可能 |

### 3.2 LLM タグの書き換え(粉川氏側で必須)

両 yaml の `llm.model` を、上記で pull した実際のタグ名に書き換えてください。

**例**(`scenario_alien_100.yaml` 該当箇所):

```yaml
llm:
  # ⚠️ ここを実際のタグに書き換えてください
  model: "huihui_ai/qwen3-uncensored:34b"   # ← あなたの環境の正しいタグ名へ
  max_tokens: 150
  think: false  # 思考可視化を見たいなら true(議事録 §2.2 で粉川氏が魅力と評価したフィーチャ)
```

## 6. 完走後の確認

### 6.1 出力物

各シナリオの `output/<scenario>/` に以下が生成されます:

- `messages.jsonl` — 全 agent の発話・受信ログ
- `events.jsonl` — place_change、memory_added、memory_evicted 等
- `memory_reasoning.jsonl` — 内面ログ
- `metrics.json` — gini / pair_stability / silent_rate(`analyze_run` で生成)
- `run_metadata.json` — 再現性確認用(seed / agents / scenario_label)
- `frames/frame_NNNN.png` — 各 step のフレーム
- `simulation.mp4` — 動画(5 fps)

### 6.2 創発が起きたかの定量チェック

```powershell
$env:PYTHONIOENCODING = "utf-8"
.\.venv\Scripts\python.exe `
    docs\04_モデル検証\conversation_check\check_conversation.py `
    prod_v2_alien_100 prod_v2_zero_gravity_100 --out=D_100agents.md
```

**期待値**(M-10 で 5 体ランで達成した健全レンジ):

| 指標 | 期待値 |
| --- | --- |
| `echo_mean` | < 0.05 |
| `echo_max` | < 0.5 が理想(短文の偶然一致は残る)|
| `reflection_mean` | 0.10〜0.30 |
| `self_similarity` | < 0.2 |

これを大きく外れる場合は、**ステージ A〜C の対策が 100 体規模で効いていない**サイン。`docs/03_ToDo/2026-04-30_問題解決ToDo.md` の §A〜C を再確認してください。

### 6.3 観察すべき創発(粉川氏に判断していただきたい点)

- **派閥**:特定 MBTI 同士で発話が偏るか
- **沈黙率**:何 % の agent が一度も発話しないか(規模が押し付ける役割分化)
- **話題の伝播**:1 人が発した語(例「逃げる」「待つ」)が何 step 後に何人へ届くか
- **国籍の影響**:LLM が学習した国籍バイアスが応答にどう出るか
- **(2026-05-01 追加)personal_context の効果**:`personal_contexts_pool`(yaml に 16 件)から各エージェントへランダム抽選される生活の文脈(家族・趣味・体調・気にしていること・詳しい分野)が、発話にどこまで滲むか。私側の 5 体 4B ラン(`output/seg2_check_alien_5/`)では前半〜中盤まで効いた([M-13](../04_モデル検証/2026-05-01_M-13_インプット側多様化_段2_3.md))が、4B では後半でエコー収束する傾向あり。34B + 100 体 で同じ現象が出るか観察してください
- **(2026-05-01 追加)知覚の非対称化**:`AlienEvent` は `near_radius=8.0` / `visible_radius=18.0`(yaml で調整可)で距離帯ごとに知覚内容が変わる。UFO 至近の人は詳細視認、遠望の人は「遠くに UFO らしきもの」、視認外は会話伝播でのみ知る。「先に見た人」と「後から会話で聞いた人」の発話分離が観察できるはず

## 8. トラブルシューティング

| 症状 | 対応 |
| --- | --- |
| `Cannot connect to Ollama` | `ollama serve` で Ollama が起動しているか確認。ポートは 11434 |
| `unknown event type: ...` | yaml の `events:` セクションが正しいか確認。`type: alien` または `type: zero_gravity` |
