## 4. システムプロンプト(エージェント属性)の確定

### 4.1 採用する変数

| 変数 | 設定 | 補足 |
| --- | --- | --- |
| 国籍 | **ランダム** | 「日本語で回答してください」のみ制約として固定 |
| 年齢 | あり | |
| 性別 | あり(男/女) | LLMはジェンダーレス概念を扱えない可能性が高いため生物学的のみ |
| **MBTI** | **あり** ⭐ | 役職/職業の代わりに性格次元として採用 |

### 4.2 あえて入れない変数
- **役職 / 職種 / ロール**: 自然発生を観察するため意図的に未設定
- 出身地 / 学校 / 偏差値 等: バイアスが強く創発を制約する懸念

### 4.3 MBTI採用の経緯
- タコさんは元・人材育成業のため「ロールを与えたい」バイアスがあると自己認識
- 粉川氏は元・製造業のため「役割で考える思考」を破壊したい意向
- 双方が「役割ベースを脱したい」点で一致 → **MBTI**に着地(指数が少なく、旬で、役割ではない性格次元)
- 個別ロール(エンジニア/PM等)は**LLM自身に内部で割り振らせる**前提

### 4.4 1エージェントあたりのシステムプロンプト雛形

私は{年齢}代の{性別}です。
国籍: {ランダム}
