# 03_1階(物) 設計

オフィスの物理空間モデル。エージェントが占有・移動する「場」の定義。

> 本書は [2026-04-24 ミーティング §5.1](../../02_ミーティング/2026年4月/02_議事録/2026年4月24日.md) の決定事項に基づく。
>
> ⚠️ **位置付け**: たたき段階であり、実装前のレビュー・議論・上書きを前提とする。

## このフォルダの狙い

1. 「オフィス(会議室を内包)」という最小スコープを、実装可能な水準まで具体化する
2. 環境量(2階)・世界の法則(3階)と切り離し、**物の階だけ** で完結する責務を確定する
3. 4 象限(都心/地方 × 大企業/スタートアップ)を、物理モデル共通 + ペルソナ・集団サイズで吸収する設計に落とす
