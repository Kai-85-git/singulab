# 01_議事録からの決定

1階(物)で何を設定するかは、[2026-04-24 ミーティング §5.1](../../02_ミーティング/2026年4月/02_議事録/2026年4月24日.md) で議論し、最小スコープとして「オフィス」のみを採用すると決定した。

## 1. 決定事項

| 項目 | 方針 | 出典 |
| --- | --- | --- |
| 設定する場 | **オフィス**(会議室を内包する前提) | §5.1 |
| 階層との切り分け | 物理的に存在する場のみを 1 階で扱う | §5.1 / §6.6 |
| 環境量(景気・空気感) | 1 階では扱わず [2階](../../04_2階-環境/) へ移譲 | §5.2 |
| 世界の法則(到達距離・認知限界) | 1 階では扱わず [3階](../../05_3階-物理-重力/) へ移譲 | §5.3 |

## 2. なぜ「オフィス」だけか

1階は **「物」= 物理的に存在する場所** に限定する。これは [3階層モデル設計](../../01_要件定義/03_機能要件/03_3階層モデル設計.md) で示した分離原則(物 / 環境 / 世界の法則)を維持するためである。

- **観察対象が業務シミュレーションである** → オフィスが最小単位として必要
- **会議室はオフィス内の区画として表現できる** → 別フロア化や独立建物にする必要はない
- **屋外・通勤・自宅は MVP では創発観察に寄与しない** → スコープ外([08_スコープ外](08_スコープ外.md))

## 3. 議論で見送った案

| 検討案 | 見送り理由 |
| --- | --- |
| 部署別フロア | 集団サイズと役割で代替できる(4 象限はペルソナで吸収) |
| 屋外・通勤路 | 業務シミュレーションの本筋から外れる |
| 自宅・リモート拠点 | リモート/オフィスの差は「コミュニケーション到達距離」(3階)で表現できる |
| 複数オフィスの並列 | 集団サイズ実験で代替可能、シナリオ複雑度を下げる |

## 4. この決定が後段に及ぼす影響

- [02_空間モデルの基本方針](02_空間モデルの基本方針.md): 「単一オフィス + 内包する会議室」を満たす最小モデル(2D 連続座標 + place 単位)を採用
- [04_場の内訳と役割](04_場の内訳と役割.md): place は `main_office` と `meeting_room` の 2 つに固定
- [06_4象限との関係](06_4象限との関係.md): 物理モデルは全象限で共通とし、象限差はペルソナと集団サイズで吸収
