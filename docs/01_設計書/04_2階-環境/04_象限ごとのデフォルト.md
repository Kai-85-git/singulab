## (旧)4 象限ベースの景気デフォルト

4 象限([1階 §6](../03_1階-物/06_4象限との関係.md))に対する景気のデフォルト割り当て。比較実験の出発点として固定する。

## 1. デフォルトマトリクス

| | 地方 | 都心 |
| --- | --- | --- |
| **大企業** | `neutral` | `neutral` |
| **スタートアップ** | `bad`(余裕がない) | `neutral` |

- 「大企業」は資金体力があるため景気の悪影響を吸収しやすい想定 → `neutral`
- 「スタートアップ × 地方」は景気の悪化が直接資金繰りに効くため `bad` を仮置き
- 「スタートアップ × 都心」は資金調達環境が比較的良いため `neutral`

> ⚠️ あくまで **仮置きのデフォルト** であり、比較実験では各セルで景気を振って挙動差を確認する。

## 2. デフォルト値の根拠

各セルの根拠を明示する。

| 象限 | 景気 | 根拠 |
| --- | --- | --- |
| 都心 × 大企業 | `neutral` | 資金体力 + 立地の双方で外的ショックを吸収しやすい |
| 地方 × 大企業 | `neutral` | 資金体力で吸収。立地のハンデは「情報の遅延」(3階)で表現 |
| 都心 × スタートアップ | `neutral` | 立地による調達アクセスで吸収。組織の若さは集団サイズで表現 |
| 地方 × スタートアップ | `bad` | 資金体力も立地アクセスも持たない最も脆弱な組み合わせ |

## 3. 比較実験での振り方

固定デフォルト + 比較実験用バリエーションを以下のように切る。

### 3.1 ベースライン(全 4 セル)

各象限のデフォルトをそのまま使う。創発パターンの初期観察に用いる。

### 3.2 景気感度実験(全 4 セル × 3 値)

各象限を `good` / `neutral` / `bad` の 3 通りで回す(計 12 ラン)。同じ象限でも景気差で創発がどう変わるかを切り分ける。

### 3.3 集中比較(2 セルのみ × 3 値)

時間がない場合の最小実験。「最も対照的な 2 セル」 = `都心 × 大企業` と `地方 × スタートアップ` だけを 3 値で回す(計 6 ラン)。

## 4. デフォルト値が将来変わりうる場面

以下のような観察結果が出た場合、デフォルトは見直す。

| 観察 | 想定される変更 |
| --- | --- |
| `地方 × スタートアップ × bad` で全ランが破滅的に同じ挙動になる | 既定値を `neutral` に戻し、bad は明示実験のみで使う |
| 大企業セルでも景気が強く効くと判明 | 大企業デフォルトも 2 段階(good / neutral)に分ける |
| 景気が他象限差を覆い隠す | 比較実験では景気を全セルで neutral 固定にし、景気は別実験で振る |

→ いずれも「観察に基づいて仮説を更新する」設計の前提([3階層モデル設計 §4](../../01_要件定義/03_機能要件/03_3階層モデル設計.md))。

## 5. config 上の表現

シナリオ yaml で象限ごとの景気を選ぶ。

```yaml
# scenario_local_startup.yaml
environment:
  economy: bad         # 地方 × スタートアップ のデフォルト

# scenario_urban_enterprise.yaml
environment:
  economy: neutral     # 都心 × 大企業 のデフォルト
```

- 同じ景気でも象限の差(集団サイズ・ペルソナ)で挙動が変わる
- 設定スキーマは [06_システム設計/03_設定スキーマ](../../06_システム設計/03_設定スキーマ/) と整合
