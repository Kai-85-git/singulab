# 04_2階(環境) 設計

物理空間に被さる環境パラメータ。**景気のみ軽く付与**、他は創発として観察する。

> 本書は [2026-04-24 ミーティング §5.2](../../02_ミーティング/2026年4月/02_議事録/2026年4月24日.md) の決定事項に基づく。
>
> ⚠️ **位置付け**: たたき段階であり、実装前のレビュー・議論・上書きを前提とする。

## このフォルダの狙い

1. 「景気だけ与え、それ以外は与えない」という最小構成を、実装可能な水準まで具体化する
2. 「あえて設定しない」3 項目を **観察対象** として残すための運用ルールを明文化する
3. 拡張時に「設定しない」原則を踏み越えないための判断基準を残す
