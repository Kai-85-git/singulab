# 02_エージェント属性

> 2026-04-29 議事録 §4 で大幅改訂。**役割系の属性をすべて削除し、性格次元(MBTI)を導入**した。

## 1. 採用する変数

| 変数 | 設定 | 補足 |
| --- | --- | --- |
| **年齢** | あり | 数値で付与 |
| **性別** | あり(男 / 女) | LLM はジェンダーレス概念を扱えない可能性が高いため生物学的のみ |
| **国籍** | **ランダム** | 「日本語で回答してください」のみ制約として固定 |
| **MBTI** | **あり ⭐** | 16 タイプから選定。役職/職業の代わりとなる性格次元 |

## 2. あえて入れない変数

- **役職 / 職種 / ロール**: 自然発生を観察するため意図的に未設定
- **男女比の固定**: 8:2 のような比率も外し、ランダムまたは試験条件で振る
- **出身地 / 学校 / 偏差値 等**: バイアスが強く創発を制約する懸念
- **国籍別の人数閾値**: 当初「10 人中 1 人外国人」のような設計だったが、ランダム配分に変更

## 3. MBTI 採用の経緯

- タコさん(元・人材育成業)は「ロールを与えたい」バイアスがあると自己認識
- 粉川氏(元・製造業)は「役割で考える思考」を破壊したい意向
- 双方が「役割ベースを脱したい」点で一致 → **MBTI に着地**(指数が少なく、旬で、役割ではない性格次元)
- 個別ロール(エンジニア/PM 等)は **LLM 自身に内部で割り振らせる** 前提

## 4. システムプロンプト雛形(1 エージェントあたり)

```
私は{年齢}代の{性別}です。
国籍: {ランダム}
MBTI: {16タイプから選定}
日本語で回答してください。
```

## 5. 設計ポリシー(兵頭氏アドバイス準拠)

- **指示を書きすぎない**。プロンプトで命令するほど創発が死ぬ
- 役職・階層は「勝手に役割が決まっていく」様を観察したいのであえて定義しない
- LLM の国籍差(モデルが学習した国による性格差)も観察対象として扱う
- 「考えすぎない、感覚で投げ込む」方が創発が出やすい(2026-04-29 議事録 §3.4)
