# 07_成功基準

> **2026-04-29 議事録で集団サイズが 5/100 に確定** したため、可変人数の閾値探索は本フェーズの成功基準から外した。

## 必達

- [ ] 小集団(5 人)・大集団(100 人)で **意思決定プロセスに観測可能な差異** が現れること
- [ ] 「あえて設定しない」項目(役職・合意形成・発言権)が **勝手に創発** し、ログから抽出できること
- [ ] 創発イベント(宇宙人 / 無重力)に対する **想定外の反応** が観察できること(プラン B = 未知のイベントを採用した動機の検証)
- [ ] 100 ステップが現実的時間内で完走すること
- [ ] 思考(Thinking)とメッセージのやりとりを動画 + PDF に可視化できること

## 望ましい

- [ ] 2 シナリオ(宇宙人 / 無重力)の両方を完走させ、面白い方を提出
- [ ] MBTI が創発に与える影響(同じ集団で MBTI 分布を変えると挙動が変わるか)の予備観察
- [ ] 国籍ランダムによる「LLM の国籍バイアス」の観察

## 本フェーズで諦めるもの

- 「何人から大集団化するか」の閾値探索(可変人数が前提だったが、5/100 固定に変更したため対象外)
- 統計的有意性(N=1〜2 試行に留まる見込み。提出後の継続検証へ)
