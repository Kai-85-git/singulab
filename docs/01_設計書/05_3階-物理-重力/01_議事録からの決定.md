# 01_議事録からの決定

3 階(世界の法則)で何を設定するかは、[2026-04-24 ミーティング §5.3](../../02_ミーティング/2026年4月/02_議事録/2026年4月24日.md) で議論し、**人間のキャパシティに相当する 3 法則のみ設定し、合意形成と発言権は創発として観察する** と決定した。

## 1. 決定事項

| 法則 | 設定 | 理由 |
| --- | --- | --- |
| コミュニケーション到達距離 | ✅ 設定 | 物理的・空間的制約。LLM が「全員に同時に話しかける」のを防ぐ |
| 情報伝達の遅延 | ✅ 設定 | リアルタイム性の限界。対面 vs 伝聞の差を作る |
| 認知限界(ダンバー数) | ✅ 設定 | 人間の記憶・認識の制約。LLM の無限記憶を抑える |
| 合意形成ルール(多数決/全会一致/リーダー決定) | ❌ **設定しない** | **本シミュレーションの最大の観察論点** |
| 発言権の分配 | ❌ **設定しない** | 決めたら結果がそのとおりになり、創発が観察できない |

## 2. 「設定する 3 法則」と「設定しない 2 項目」の境界

3 法則と 2 項目を分ける基準は **「人間のキャパシティに相当するか」** である。

| 観点 | 設定する 3 法則 | 設定しない 2 項目 |
| --- | --- | --- |
| 個人で破れるか | 破れない(物理・生理の限界) | 破れる(合意の取り方は社会的規約) |
| LLM が無自覚に超越するか | する(到達距離・記憶を無限とみなす) | しない(LLM は合意形成ルールを与えなければ自分で選ぶ) |
| 観察したい創発に直結するか | 直接の対象ではない(前提条件) | 直接の対象 |

→ この基準の詳細は [02_設計の核](02_設計の核.md)。

## 3. 議論で見送った案

| 検討案 | 見送り理由 |
| --- | --- |
| 重力・物理力の本格導入 | 業務シミュレーションでは重力は意味を持たない(フォルダ名「重力」は階層比喩) |
| 視覚到達距離(誰が見えるか) | 到達距離(音声)で十分。視覚は会議室の壁/ドア概念と同時に必要になる |
| 疲労・睡眠の限界 | ダンバー数(認知限界)に内包させる。独立に持つと観察軸が分散する |
| 寿命・退職 | シミュレーション 1 ラン内で扱うべきではない。比較実験の安定性を損なう |
| 多数決の比率(過半数 / 2/3 等) | 合意形成は **観察対象** であり、ここで決めるとゴールとぶつかる |

## 4. 「重力」というフォルダ名の意味

フォルダ名 `05_3階-物理-重力` の **「重力」は階層フレームワークの比喩** である(議事録 §6.6)。

- 1階 = 物(机の上の物体)
- 2階 = 環境(机の上の温度・湿度)
- 3階 = **物理・重力**(物を地面に押し付ける根源的法則)

つまり「誰も逆らえない世界の法則」のメタファーとしての「重力」であり、実装上の重力加速度 `g = 9.8` を持つ意味ではない。
