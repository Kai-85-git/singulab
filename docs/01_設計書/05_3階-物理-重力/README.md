# 05_3階(世界の法則) 設計

「誰も逆らえない世界のルール」。**人間のキャパシティに相当する 3 法則のみ設定**、合意形成・発言権は創発として観察する。

> 本書は [2026-04-24 ミーティング §5.3](../../02_ミーティング/2026年4月/02_議事録/2026年4月24日.md) の決定事項に基づく。
>
> ⚠️ **位置付け**: たたき段階であり、実装前のレビュー・議論・上書きを前提とする。

## このフォルダの狙い

1. LLM が「人間を超越」しないよう、**人間のキャパシティ内に法則を収める** という設計哲学を明文化する
2. 3 法則(到達距離 / 遅延 / 認知限界)を実装可能な水準まで具体化する
3. 「合意形成」「発言権」を **観察対象として残す** ための運用ルールを定める
4. 拡張時に「設定しない」原則を踏み越えないための判断基準を残す
