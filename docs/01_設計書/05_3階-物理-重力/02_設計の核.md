# 02_設計の核

3 階の設計思想 = **「LLM が人間を超越しないよう、人間のキャパシティの範囲内に法則を収める」**。

## 1. なぜ「人間のキャパシティ」なのか

LLM は放っておくと以下のように振る舞う。

| 放置時の LLM の挙動 | 業務シミュレーションへの悪影響 |
| --- | --- |
| 全エージェントの発話を全エージェントが受信できる | 「会議室で話したことが廊下にいる人にも筒抜け」 → 派閥や口コミの創発が消える |
| すべてのメッセージが瞬時に届く | 「対面 vs 伝聞」の差が消え、伝言ゲーム・歪曲の創発が消える |
| 過去の全発話を完全に記憶する | 「忘れる」「思い込む」がなくなり、誤解・齟齬の創発が消える |
| 100 人全員の名前と関係性を完璧に把握する | 派閥形成・親密度の差が出ない |

これらは **人間ならば物理・生理の限界で自動的に制約される** ことだが、LLM には制約がない。3 階の役割は **その差分を埋めること**。

## 2. 3 法則と人間の対応

| 3 階の法則 | 対応する人間の限界 | 既知の研究・経験則 |
| --- | --- | --- |
| コミュニケーション到達距離 | 声・ささやきが届く物理範囲 | 5〜10m で雑音に埋もれる、3m 以内なら明瞭 |
| 情報伝達の遅延 | 対面以外は時差がある | メール・チャットは数分〜数時間、伝言は人を介した分の時間 |
| 認知限界(ダンバー数) | 安定した社会関係を保てる人数の上限 | 親密圏 ~5、信頼圏 ~15、知人圏 ~50、ダンバー数 ~150 |

> ⚠️ いずれも **再現精度は重視しない**。観察対象である「派閥形成」「うわさの伝播」「合意形成」が成立する **桁オーダー** さえ合っていれば十分。

## 3. 「設定する」と「設定しない」の境界

設定する側と設定しない側を分ける 3 つの基準。

### 3.1 個人の意思で破れるか

- 破れない → **設定する**(物理・生理の限界)
  - 例: 100m 離れた相手にささやきは届かない
- 破れる → **設定しない**(社会的規約)
  - 例: 多数決のルールは合意で変えられる

### 3.2 LLM が無自覚に超越するか

- 超越する → **設定する**(明示的に制約しないと無限になる)
  - 例: 記憶上限。指定しないと LLM は全コンテキストを使う
- 超越しない → **設定しない**(自分で何かしらの規範を作る)
  - 例: 合意形成。何も指示しなくても LLM 同士が方法を選ぶ

### 3.3 観察したい創発に直結するか

- 直結しない(前提条件) → **設定する**
- 直結する(観察対象) → **設定しない**

3 つの基準すべてで「設定する」側に来た 3 法則だけを採用する。

## 4. 仮値の決め方

3 法則の数値は **観察したい現象の桁を逆算** して決める。

| 法則 | 観察したい現象 | 仮値の根拠 |
| --- | --- | --- |
| 到達距離 | 大集団で「届く範囲が限られる」 | オフィス幅 20 ユニットに対し 3〜5 にすれば「半径 1/4 程度しか届かない」状況になる |
| 遅延 | 対面 vs 伝聞の差 | 対面 0、place 間 3〜5。1 ステップ ≒ 1 ターンの感覚で「数巡先」になる |
| 認知限界 | 派閥が固まる | 親密圏 5〜15 を目安。集団 100 人で K=30 なら「全員は覚えられない」が成立 |

仮値は実験で振って調整する([07_実装方針 §5](07_実装方針.md))。

## 5. 「設定しない」を貫く意味

合意形成・発言権を「設定しない」のは、**シミュレーションの目的そのもの** である。

- これらが自然発生するか、しないかが **本シミュレーションの最大の問い**
- 「設定」した瞬間、答えがそのまま結果になる(自己充足的予言)
- 観察結果の言語化として「ダンバー数 30、到達距離 5、遅延 3 という制約下で、合意形成は◯◯という形で創発した」と書けるのが理想
