# 07_ペルソナ拡張(2026-04-29 改訂版)

> 2026-04-29 議事録 §4 で **役割ベースの属性を全廃し、MBTI を性格次元として導入**。
> 本ドキュメントは新スキーマの設計指針。
>
> 旧設計(role / origin / tenure_years / location_label など)は Phase 3-1 で実装済みだが、Phase 5 で本スキーマに置き換える。

## 1. 採用するペルソナフィールド

| フィールド | 型 | 値 / 範囲 | 割当 |
| --- | --- | --- | --- |
| `age` | int | 20〜70 | `uniform` 範囲指定でランダム |
| `gender` | enum | `male` / `female` | LLM はジェンダーレス概念を扱えない可能性が高いため生物学的のみ |
| `nationality` | str | 任意の国名(任意プール) | `random` でプールから抽選。**「日本語で回答してください」プロンプトで言語のみ固定** |
| `mbti` | enum | INTJ / INTP / ENTJ / ENTP / INFJ / INFP / ENFJ / ENFP / ISTJ / ISFJ / ESTJ / ESFJ / ISTP / ISFP / ESTP / ESFP | `random` で 16 タイプから |

**意図的に入れないフィールド**:

- `role` / `job` / `position`(役職・職種・ロール)→ 自然発生を観察するため
- `tenure_years`(社歴)→ 役職と紐付くため
- `location_label` / `company_type_label`(都心/地方 × 大企業/スタートアップ)→ 4 象限切り廃止に伴い廃止
- `origin`(出身地・偏差値・学校歴)→ バイアスが強く創発を制約する懸念

## 2. config(yaml)スキーマ案

```yaml
agents:
  num_agents: 5    # 5 / 100 のいずれか(2026-04-29 議事録 §5)
  persona:
    age:
      assignment: uniform
      range: [20, 60]
    gender:
      assignment: random
      values: [male, female]
    nationality:
      assignment: random
      pool: [日本, 米国, 中国, インド, ブラジル, ドイツ, フランス, 韓国, ベトナム]
    mbti:
      assignment: random
      values: [INTJ, INTP, ENTJ, ENTP, INFJ, INFP, ENFJ, ENFP,
               ISTJ, ISFJ, ESTJ, ESFJ, ISTP, ISFP, ESTP, ESFP]
```

`pool` を空にすると国籍は `日本` 固定。MBTI を空にすると省略(対照群として使用可)。

## 3. プロンプトでの表現

`Persona.to_prompt()` は `=== PERSONA ===` セクションに以下を出す(議事録 §4.4 雛形に整合):

```
私は{age}代の{gender_jp}です。
国籍: {nationality}
MBTI: {mbti}
日本語で回答してください。
```

例:

```
私は30代の男性です。
国籍: ブラジル
MBTI: ENFP
日本語で回答してください。
```

> **言語制約は LANGUAGE REQUIREMENT セクションでも別途強制** していて、ここの 1 行は「LLM の自己認識を整える」ための重複指定。M-06 の対策とセットで運用する。

## 4. メタデータ出力

`run_metadata.json` の `personas` フィールドに各 agent の生成結果を保存:

```json
{
  "personas": [
    {"id": 0, "age": 32, "gender": "male", "nationality": "日本", "mbti": "INTJ"},
    {"id": 1, "age": 45, "gender": "female", "nationality": "中国", "mbti": "ENFP"}
  ]
}
```

提出 PDF では「**MBTI 分布が創発に与える影響**」を観察軸として PDF に転記する想定。

## 5. 観察したい仮説(議事録 §4 + 4 月 29 日所感)

- **MBTI が同じだけのグループは均質に喋る** → pair_stability ↑、gini ↓
- **MBTI が極端に偏った集団**(全員 ENFP / 全員 INTJ 等)では合意形成パターンが変化
- **国籍がランダムに混じる**ことで、LLM が学習した文化バイアスが creativity に影響するか
- **役職を与えなくても役割が自然発生する** → messages.jsonl から「リーダー的発話」「同調的発話」を抽出して観察

## 6. 旧スキーマ → 新スキーマの差分(実装メモ)

| 旧 | 新 |
| --- | --- |
| `name`(田中・佐藤など) | **削除**(役割を連想するため) |
| `role`(エンジニア・PM 等) | **削除** |
| `tenure_years` | **削除** |
| `location_label` / `company_type_label` | **削除**(4 象限切り廃止) |
| `gender`(male / female) | 維持 |
| ─ | **追加** `age`(数値範囲) |
| ─ | **追加** `nationality`(プール抽選) |
| ─ | **追加** `mbti`(16 値) |

→ Phase 5(MBTI ペルソナ + 創発イベント実装)で `src/agent/persona.py` を書き換える。
