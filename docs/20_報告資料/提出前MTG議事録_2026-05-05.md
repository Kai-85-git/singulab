## 2. 観察結果の共有(本ハッカソンのコア成果)

### 2.1 ペルソナ設定の必要性(F-2 系の重要発見)

- 当初の最小構成では「会話にすらならない」事象が発生
- ペルソナ(年齢・性別・国籍・MBTI + `personal_context`)を入れないと、エージェントが何をしてよいか分からず話が進まない
- **コントロールしすぎると恣意的になり、何も与えないと会話自体が成立しない**という両端の存在を実体験で確認 → 観察対象として価値ある気づき

### 2.2 5体ランの観察(`prod_v3_alien_5`)

- 5体のうち、**57歳の男性役**が冒頭から「やさぐれた」発言で会話を開始
  - セーフティ付きモデルではおそらく出ない反応
  - abliterated(リミッターカット)モデルだから本音らしき表現が出てきたと推測
  - **粉川氏が一番面白かった観察**として推している
- UFO(15 step で出現)は「視認できない」設定 → それでも一部の人物が「風が違う」「光を感じる」など**第六感的な兆候**を察知
- 結果的に「視覚的に感じ始めた人(2名)」「無関心(1名)」の分化が観察された
- 50代男性 / 20代女性 / 1名(無関心) の構図

### 2.3 100体ランの観察(`prod_v3_alien_100_v2`)

#### グループの自然形成
- 人と人が会話できる距離を **実距離 5〜8m** 相当に設定(現実の対面会話の参考値から)
- グループが自然に形成される様子が線でつながって可視化できた

#### 移動バイアス(新発見・要深堀り)
- 5体・100体いずれも **30 step 進めると全体が右(やや右上)に移動する** 傾向
- LLM 内部に方向バイアスがある可能性 → 今後の探求テーマとして粉川氏がメモ

#### ⭐ 自律的な仕事開始 / 専門家モード(本提出物の主役素材)
- 100体の中の数体(エージェント番号 5 / 13 / 57 ほか)が**自分で考えて仕事を始めた**
  - 例:会話の流れから「給湯器が焦げてる感じがする」を拾い、「給湯器を直そうか」と動き始めた
  - 役割を明示的に与えていないのに役割を全うするエージェントが出現
- 「**電気設備の問題について詳しく説明させていただきます**」と UFO 騒動を電気の問題として独自解釈し、**説明者役**に転化したエージェントを観察
- 一人がここまで自律的になると「LLM 自体に意識はあるか」という哲学的問いにつながる、と粉川氏

#### 5つのスタイルへの分化
- 指示なしで「好奇心系 / 構成派 / 警戒班」などの行動パターンが分化
- **警戒班ペア**(同じ警戒スタイル同士でペアになる)も観察

### 2.4 知覚距離の調整(失敗 → 解決)

- 100体では「office が大きく」「光や勘の感覚を一般人レベルに設定」したため、**情報が遮断 + 自分たちの話題が優位**になり、UFO 言及がほぼ出ない事態が発生
- **影響範囲(visible_radius)を拡大**して再走 → 観察として面白い結果に到達
- 「**5体パラメータの 100体への流用は要慎重**」「office カバレッジ率(%)で揃えるべき」が技術的ファインディング

### 2.5 100体の人口構成

- 男:女 = 8:2(80人:20人)
- 外国人 10%(ブラジル / ドイツ など、複数国籍をミックス)
